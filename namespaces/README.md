- Native-speaker reviewed prompt set for that language
- At least one documented activation / scoring run
- Language-specificity and D6/D3 baseline numbers recorded
- Status file updated from SCAFFOLD → BASELINE_READY

Only then may comparative or multi-namespace experiments begin.
